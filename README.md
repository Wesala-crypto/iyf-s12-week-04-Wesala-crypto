# IYF WeCan Academy – Week 4: JavaScript Fundamentals

## Introduction

This repository contains my Week 4 learning activities for the IYF WeCan Academy Season 12 programming course.

The week focuses on understanding JavaScript fundamentals, working with arrays and objects, manipulating data, and solving practical programming challenges.

## Learning Objectives

- Understand JavaScript variables and data types.
- Work with operators and conditional statements.
- Understand loops and functions.
- Manipulate arrays and objects.
- Use array methods to process data.
- Understand JSON parsing and stringifying.
- Apply JavaScript concepts in practical projects.

## Lessons and Activities

### Lesson 7: JavaScript Basics

Topics covered:

- Variables: `let`, `const`, and `var`.
- Data types and operators.
- String manipulation.
- Comparison and logical operators.
- Functions and arrow functions.
- Conditional statements.
- Loops.
- FizzBuzz exercise.
- Basic calculator.

### Lesson 8: Arrays, Objects and Data Manipulation

Topics covered:

- Creating and modifying arrays.
- Array methods: `push()`, `pop()`, `shift()`, and `unshift()`.
- Using `map()`, `filter()`, `find()`, `forEach()`, and `reduce()`.
- Creating and accessing objects.
- Object methods and properties.
- Working with arrays of objects.
- JSON parsing using `JSON.parse()`.
- JSON conversion using `JSON.stringify()`.

## Mini-Project: Student Grade Tracker

Built a Student Grade Tracker using JavaScript objects and methods.

The application supports:

- Adding students and their grades.
- Finding students by name.
- Calculating individual student averages.
- Calculating class averages for specific subjects.
- Identifying the top-performing student.
- Identifying students who need academic support.
- Assigning letter grades.
- Generating student report cards.

## Technologies Used

- JavaScript
- HTML

## How to Run

Make sure Node.js is installed.

Run the main JavaScript exercises:

```bash
node main.js
```

Run the daily challenges:

```bash
node challenges.js
```

## Key Lessons Learned

Through these activities, I developed a better understanding of how JavaScript works and how it can be used to solve practical problems.

I learned how to manipulate data using arrays and objects, write reusable functions, use loops and conditions, and process JSON data.

The Student Grade Tracker helped me combine different JavaScript concepts into one practical application.
